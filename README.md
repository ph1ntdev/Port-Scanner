# Port-Scaner
## Building code
### Requirement
- cmake version 4.4.4
### How to build
1. Clone the repo to any directory using `git clone https://github.com/ph1ntdev/Port-Scanner.git && cd Port-Scanner`.
2. Add directory `build` using `mkdir build && cd build`.
3. Using `cmake .. && cmake --build .` you build and compile program.
4. Run program using `./port-scanner`.
